Relaxation: the one operation they all share

RELAX(u, v)
  if d[u] + w(u,v) < d[v]
      d[v] = d[u] + w(u,v) ; parent[v] = u

Initialise \(d[s]=0\) and \(d[v]=\infty\) otherwise. Let \(\delta(v)\) be the true distance.

Upper-bound invariantAt all times \(d[v]\ge\delta(v)\), and \(d[v]\) (when finite) is the length of some actual \(s\)–\(v\) walk. It never increases.
Path-relaxation propertyIf \(s=v_0,v_1,\dots,v_k\) is a shortest path and its edges are relaxed in this order (other relaxations may be interleaved), then afterwards \(d[v_k]=\delta(v_k)\).
Each algorithm is a relaxation order
  • DAG: topological order: every path's edges are relaxed in order.
  • Dijkstra: in order of final distance, which needs \(w\ge0\).
  • Bellman–Ford: all edges, \(n-1\) times, so any path of \(\le n-1\) edges gets its edges relaxed in order.

Dijkstra: why non-negative weights are essential

Dijkstra repeatedly extracts the unvisited vertex \(u\) with minimum \(d[u]\), marks it final, and relaxes its out-edges.

ClaimWhen \(u\) is extracted, \(d[u]=\delta(u)\).
ProofSuppose not, and let \(u\) be the first extracted vertex with \(d[u]>\delta(u)\). Take a shortest \(s\)–\(u\) path and let \(y\) be its first vertex not yet extracted, with predecessor \(x\) (extracted, so \(d[x]=\delta(x)\)). Since \(x\) was relaxed, \(d[y]=\delta(y)\). The rest of the path from \(y\) to \(u\) has non-negative length, so \(\delta(y)\le\delta(u)\). Hence \(d[y]=\delta(y)\le\delta(u)<d[u]\), yet \(u\) was extracted before \(y\) (the minimum): a contradiction.

Cheaper special cases: DAGs and small integer weights

DAG shortest (or longest) paths

for u in topological order
    for each edge (u, v): RELAX(u, v)

Correct for any weights: by the path-relaxation property, every path's edges are relaxed in order. \(O(n+m)\). The longest path in a DAG = the shortest with negated weights: critical path scheduling.

Integer weights in \([0,C]\)

  • Dial: buckets indexed by distance (a circular array of \(C+1\) buckets). \(O(m+nC)\) (pseudo-polynomial in \(C\): L07!).
  • 0-1 BFS: weights in \(\{0,1\}\). Use a deque: push the target of a 0-edge to the front and of a 1-edge to the back. \(O(n+m)\).
  • Radix heaps: \(O(m+n\log C)\), polynomial in the input length.
Longest paths are easy in DAGs and NP-hard in general graphs. The DAG assumption is doing all the work.

Bellman–Ford: correctness and negative cycles

BELLMAN-FORD(G, s)
  initialise d
  repeat n − 1 times
      for each edge (u,v): RELAX(u,v)
      if nothing changed: stop early
  for each edge (u,v)
      if d[u] + w(u,v) < d[v]: report "negative cycle reachable from s"

Correctness: with no negative cycle reachable from \(s\), every vertex has a shortest path that is simple, with \(\le n-1\) edges. Round \(i\) relaxes its \(i\)-th edge in order (path relaxation). Detection: if no edge can be relaxed, summing \(d[v]\le d[u]+w(u,v)\) around any reachable cycle gives cycle weight \(\ge0\).

Practical points
  • Early termination: the number of rounds is at most (edges on a shortest-path tree's deepest path) + 1. In our experiment: 15 rounds, not 200,000.
  • Whole-graph detection: add a virtual source with 0-edges to every vertex.
Legacy corrections
  • "Run BF per connected component" does not work for directed graphs: use the virtual source.
  • The queue-based variant stopped after \(n\) total pops and reported a cycle. That is wrong: count relaxations per vertex (or path lengths ≥ n).
  • An undirected edge of negative weight is itself a negative cycle.

Potentials and reduced costs

Reduced costFor any function \(h:V\to\mathbb R\) (a potential), let \(w_h(u,v)=w(u,v)+h(u)-h(v)\).

Telescoping: for any \(s\)–\(t\) path \(P\): \(w_h(P)=w(P)+h(s)-h(t)\). Every \(s\)–\(t\) path shifts by the same constant, so shortest paths are preserved. Cycles keep their weight.

Feasible potential: \(w_h\ge0\) everywhere. It exists iff there is no negative cycle.

How to find one: \(h(v)=\delta(q,v)\) from a virtual source \(q\). The triangle inequality \(\delta(q,v)\le\delta(q,u)+w(u,v)\) gives \(w_h(u,v)\ge0\).

Why this matters
  • Johnson's algorithm (next slide)
  • A*: a heuristic \(\pi\) is consistent iff \(w_{-\pi}\ge0\) (reduced costs non-negative); A* = Dijkstra on reduced costs
  • Min-cost flow: potentials keep residual costs non-negative (L12 outlook)
  • LP duality: potentials are dual variables

Johnson's algorithm and Floyd–Warshall

Johnson (1977)

  1. Add a virtual source \(q\); run Bellman–Ford: \(h(v)=\delta(q,v)\), or report a negative cycle. \(O(nm)\).
  2. Reweight to \(w_h\ge0\).
  3. Dijkstra from every vertex on \(w_h\): \(n\cdot O((n+m)\log n)\).
  4. \(\delta(u,v)=\delta_h(u,v)-h(u)+h(v)\).

Total \(O(nm+n(n+m)\log n)\) with a binary heap; \(O(nm+n^2\log n)\) with a Fibonacci heap. Best for sparse graphs.

Floyd–Warshall

\(D_k[i][j]\) = the shortest \(i\)–\(j\) path with intermediate vertices in \(\{1..k\}\):

\[D_k[i][j]=\min\big(D_{k-1}[i][j],\ D_{k-1}[i][k]+D_{k-1}[k][j]\big).\]

In-place update is safe (row and column \(k\) do not change in round \(k\) without negative cycles). \(\Theta(n^3)\) time, \(\Theta(n^2)\) space; simple and cache-friendly. Negative cycle ⇔ some \(D[i][i]<0\) at the end.

Sparse (\(m=O(n)\)): Johnson \(\approx n^2\log n\) ≪ FW \(n^3\). Dense (\(m\approx n^2\)): both \(\approx n^3\), and FW's simplicity usually wins.

Groups · 15 min

Synthesis

  1. Shortest paths are one problem with many assumptions: unweighted, DAG, small integers, non-negative, negative edges, negative cycles, sparse/dense, single/all pairs.
  2. All algorithms are relaxation orders. The proofs use the upper-bound invariant + path relaxation, and Dijkstra adds one line that needs \(w\ge0\).
  3. Name the priority queue: array \(n^2\), binary heap \((n+m)\log n\), Fibonacci \(m+n\log n\).
  4. Potentials make negative edges harmless when there are no negative cycles (Johnson), and they explain A*.
  5. Measurements can contradict worst-case intuition (heap Dijkstra on dense random graphs). Know which input families you tested.
