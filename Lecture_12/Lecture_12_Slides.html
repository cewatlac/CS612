Max-flow and min-cut

Definitions · residual graphs · Ford–Fulkerson · the theorem · Edmonds–Karp · Dinic

Flow networks, cuts, weak duality

A directed graph with capacities \(c(u,v)\ge0\), a source \(s\) and a sink \(t\). A flow \(f\) satisfies

  • capacity: \(0\le f(u,v)\le c(u,v)\);
  • conservation: inflow = outflow at every \(v\ne s,t\).

Value \(|f|\) = the net flow out of \(s\).

An \(s\)–\(t\) cut \((S,T)\): \(s\in S\), \(t\in T\). Its capacity \(c(S,T)=\sum_{u\in S,v\in T}c(u,v)\) counts only forward edges.

Lemma (flow across any cut)For every flow \(f\) and every cut \((S,T)\): \(|f|=f(S,T)-f(T,S)\le c(S,T)\).
ProofSum conservation over the vertices of \(S\): the net flow out of \(S\) equals the net flow out of \(s\), which is \(|f|\). The net flow out of \(S\) is \(f(S,T)-f(T,S)\le c(S,T)-0\).
So every cut is an upper bound on every flow: max-flow ≤ min-cut. The theorem says they are equal.

Residual graphs and augmenting paths

Residual graph \(G_f\): for each edge \((u,v)\),

  • a forward residual edge with capacity \(c(u,v)-f(u,v)\) (room to push more);
  • a backward residual edge \((v,u)\) with capacity \(f(u,v)\) (the ability to undo flow).

An augmenting path is an \(s\)–\(t\) path in \(G_f\). Pushing its bottleneck \(\Delta\) along it keeps capacity and conservation, and increases \(|f|\) by \(\Delta\).

Why backward edges are essential

Greedy "push along any path with spare capacity, never undo" can get stuck below the optimum: an early path may use an edge that two later paths needed.

The backward residual edge lets a later augmentation reroute flow. That is what makes the method complete.

Ford–Fulkerson and the max-flow/min-cut theorem

FORD-FULKERSON(G, s, t)
  f = 0
  while G_f has an s–t path P:  augment f along P by its bottleneck
  return f
Theorem (Ford & Fulkerson 1956)The following are equivalent: (1) \(f\) is a maximum flow; (2) \(G_f\) has no augmenting path; (3) \(|f|=c(S,T)\) for some cut \((S,T)\). In particular, max-flow = min-cut.
Proof(1)⇒(2): an augmenting path would increase \(|f|\). (3)⇒(1): weak duality. (2)⇒(3): let \(S\) = the vertices reachable from \(s\) in \(G_f\), so \(t\notin S\). Every edge \(S\to T\) is saturated (otherwise its head would be reachable). Every edge \(T\to S\) carries zero flow (otherwise its backward residual edge would make its tail reachable). So \(|f|=f(S,T)-f(T,S)=c(S,T)\).

Choosing the augmenting path: Edmonds–Karp and Dinic

Edmonds–Karp (1972): shortest augmenting path (BFS)

  • Lemma: the BFS distance \(d_f(s,v)\) never decreases across augmentations.
  • Each edge becomes the bottleneck ("critical") at most \(O(n)\) times: between two consecutive times, the distance of its tail grows by \(\ge2\).
  • So there are \(O(nm)\) augmentations, each \(O(m)\): \(O(nm^2)\), independent of the capacities (polynomial).

Dinic (1970): blocking flows in the level graph

  • Build the BFS level graph (edges from level \(i\) to \(i+1\)).
  • Find a blocking flow in it (DFS with current-arc pointers), then rebuild.
  • The \(s\)–\(t\) distance increases every phase: \(\le n\) phases, \(O(nm)\) each: \(O(n^2m)\).
  • Unit-capacity bipartite graphs: \(O(m\sqrt n)\) (= Hopcroft–Karp).
The generic method is correct with any augmenting path. Which path is chosen decides whether the running time depends on the capacity values (pseudo-polynomial) or only on \(n\) and \(m\) (polynomial).

Modelling with flow

Matching · the toolkit · project selection · elimination

Bipartite matching as flow

A bipartite graph \((L\cup R,E)\). Build: \(s\to\ell\) (capacity 1) for \(\ell\in L\); \(\ell\to r\) (capacity 1) for \((\ell,r)\in E\); \(r\to t\) (capacity 1).

ClaimMaximum matching size = maximum flow value.
Proof (both directions)(≤) A matching \(M\) gives a flow of value \(|M|\): one unit along \(s\to\ell\to r\to t\) for each matched pair; capacities hold because the pairs are disjoint. (≥) By integrality there is an integral maximum flow, so each edge carries 0 or 1. Unit capacity into each \(\ell\) and out of each \(r\) means each vertex is used at most once, so the middle edges with flow 1 form a matching of the same size.
König's theorem (a corollary)In a bipartite graph, max matching = min vertex cover. A minimum cut (with capacities \(\infty\) on the middle edges) corresponds to a vertex cover: \(L\setminus S\) plus \(R\cap S\).
In general graphs, maximum matching is still polynomial (Edmonds' blossom algorithm), but not via this simple flow model. And minimum vertex cover becomes NP-hard (L13).

Min-cut as an optimisation tool: project selection

Projects with profits \(p_i\) (possibly negative = cost). Prerequisites: choosing \(i\) requires choosing \(j\). Maximise the total profit of a prerequisite-closed set.

Network: \(s\to i\) with capacity \(p_i\) if \(p_i>0\); \(i\to t\) with capacity \(-p_i\) if \(p_i<0\); \(i\to j\) with capacity \(\infty\) for each prerequisite.

Claim: for a minimum cut \((S,T)\), the projects in \(S\setminus\{s\}\) are an optimal selection, with profit \(=\sum_{p_i>0}p_i-c(S,T)\).

Why

A finite cut cannot cut an \(\infty\) edge, so \(S\) is closed under prerequisites. Any closed set \(A\) gives a finite cut \((\{s\}\cup A,\ \text{rest})\).

Its capacity = (the profits of positive projects not chosen) + (the costs of negative projects chosen) = \(\sum_{p_i>0}p_i-\text{profit}(A)\).

So minimising the cut maximises the profit. A bijection between closed sets and finite cuts.

Certificates of impossibility: baseball elimination

Team \(x\) has \(w_x\) wins and \(r_x\) games left. Assume \(x\) wins all of them: \(W=w_x+r_x\). Is there an outcome of the remaining games among the other teams in which no team exceeds \(W\)?

Network: \(s\to\) (game node \(\{i,j\}\)) with capacity = the number of games left between \(i\) and \(j\); game \(\to i\) and game \(\to j\) with \(\infty\); \(i\to t\) with capacity \(W-w_i\).

\(x\) can still win iff the max flow saturates all game edges.

The certificateIf \(x\) is eliminated, the min cut yields a set \(T'\) of teams with \[\frac{w(T')+g(T')}{|T'|}>W,\] where \(g(T')\) is the number of games left among them: their average number of wins must exceed \(W\), so some team exceeds it. A one-line proof that anyone can check, found by the algorithm.

Synthesis

  1. Every cut bounds every flow (weak duality). Max-flow = min-cut, and the proof builds the cut from the residual graph.
  2. Ford–Fulkerson is correct with any augmenting path. The path rule decides pseudo-polynomial vs. polynomial: FF \(O(m|f^\ast|)\), Edmonds–Karp \(O(nm^2)\), Dinic \(O(n^2m)\) and \(O(m\sqrt n)\) on unit bipartite graphs.
  3. Integrality turns flows into combinatorial objects (matchings, assignments).
  4. Modelling = the unit, the capacities (edges, vertices, uses), conservation, and a proof in both directions. Min-cuts answer optimisation (project selection) and impossibility (elimination) questions.
  5. Some problems are not flow problems: Hamiltonian paths, "all or nothing" constraints. That is next week.
